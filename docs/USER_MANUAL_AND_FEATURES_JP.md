# AudioScope 使用方法・実装機能一覧・既知の制限事項

## 1. 基本的な使用方法

### 初回起動と音楽ライブラリの読み込み
1. アプリを起動し、「ライブラリ」画面の **「権限を許可して自動検索」** をタップして「音楽とオーディオ (`READ_MEDIA_AUDIO`)」権限を許可すると、端末内の音楽ファイルが自動スキャンされます。
2. 権限を許可しない場合でも、画面右上の **ファイルアイコン（個別ファイル選択）** や **フォルダーアイコン（フォルダー追加）** から Android 標準のファイルピッカー（Storage Access Framework）経由で曲を読み込んで再生・解析できます。
3. 上部の検索バーおよび **「ハイレゾのみ」「ロスレスのみ」** チップで瞬時に絞り込みができ、タブで **曲 / アルバム / アーティスト / フォルダー / プレイリスト / お気に入り / 再生履歴** を切り替えられます。

### 再生画面（Now Playing）の操作
上から順に以下の6要素が配置されています：
1. **アルバムアート**: ハイレゾ音源では `HI-RES`、可逆圧縮/PCM音源では `LOSSLESS` バッジを表示します。左上のボタンからリアルタイム **FFTスペクトラム / 波形 / 両方 / OFF（省電力）** を切り替えられます。
2. **曲名・アーティスト名**: 右側のハートボタンでお気に入り登録・解除が可能です。
3. **音質情報のコンパクト表示**: `FLAC`・`96 kHz`・`24 bit`・`3,102 kbps (VBR)`・`Lossless: Yes` などを一目で確認できます（右上の目のアイコンで表示 ON/OFF 切替可能）。
4. **再生シークバー**: ドラッグで任意の再生位置へシークできます。
5. **再生操作ボタン**: シャッフル、前曲、再生/一時停止、次曲、リピート（OFF / 全曲 / 1曲）を操作できます。右上のキューアイコンから再生キューの並び替え・削除も行えます。
6. **音質詳細モニターを開くボタン**: タップすると `SOURCE / OUTPUT / NETWORK` の3領域詳細画面へ遷移します。

### 音質詳細画面（SOURCE / OUTPUT / NETWORK）
- **SOURCE**: 元ファイルのコンテナ形式、音声コーデック、可逆/非可逆判定、実測ビットレート、CBR/VBR 方式、サンプリング周波数、ビット深度、チャンネル構成、再生時間、ファイルサイズ、純音声データサイズ、対PCM圧縮率、FLAC MD5、埋め込みメタデータ一覧、20kHz 超ハイレゾ帯域対応 FFT スペクトラムを表示します。
- **OUTPUT**: 現在の再生先（内蔵スピーカー / 有線 / USB DAC / Bluetooth A2DP / LE Audio）、ExoPlayer `AudioTrack` 実構成、OS ネイティブミキサー基準周波数、リサンプリング診断、USB DAC ビットパーフェクト切替スイッチ、Bluetooth 接続状態、出力デバイス切り替え履歴を表示します。Bluetooth コーデックの実使用値を確認したい場合は **「開発者向けオプションを開く」** ボタンから Galaxy S26 標準画面を直接開けます。
- **NETWORK**: ローカル再生と HTTPS ネットワーク再生を自動判別し、現在速度・セッション累積通信量・端末起動累計送受信量を `B / KB / MB / GB` 自動単位と 60 秒リアルタイムグラフで表示します。
- **テキスト共有**: 右上の **「共有」** ボタンから、SOURCE / OUTPUT / NETWORK の診断レポートをテキストとして他アプリやメモへ共有できます。

### 統計・比較ラボ（Analytics & Compare）
- 下部ナビゲーションの **「統計・比較」** タブを開くと、ライブラリ全体の形式別曲数・容量比率・ハイレゾ曲数と、任意の2曲（例：FLAC と MP3）をスロット A / B に選んで実測スペックを並列比較できるラボを利用できます。

## 3. 既知の制限事項（Android OS およびハードウェア仕様による制限）

1. **実使用中の Bluetooth コーデック・ビットレート・電波品質の直接取得不可**:
   - Android（API 37 / Android 17 を含む）では、`BluetoothA2dp.getCodecStatus(BluetoothDevice)` がシステム署名権限 `BLUETOOTH_PRIVILEGED` を要する `@SystemApi` として保護されているため、Play ストアや APK でインストールする一般アプリからは現在ネゴシエーション中のコーデック（LDAC / aptX / AAC / SBC / SSC / LC3）や LDAC の瞬時ビットレート（990 / 660 / 330 kbps）、A2DP リンクのリアルタイム RSSI を取得できません。本アプリは要件に従い非公開 API 回避や偽装表示を行わず、「取得不可（OSによる制限）」と明示した上で、確認可能な「開発者向けオプション」へのワンタップ導線を提供しています。
2. **Bluetooth 実送信パケット数・バイト数の取得不可**:
   - `TrafficStats` は Linux カーネルの IP ネットワーク層（Wi-Fi / モバイルデータ）のみを集計対象とし、Bluetooth コントローラ（HCI / L2CAP）の音声フレーム送出バイト数は公開 API に存在しません。そのため実測通信量は「取得不可」とし、AudioTrack のサンプルレート×ビット深度×チャンネル数から求めた値は必ず「【推定・PCM理論値】」として区別しています。
3. **OS ミキサー経由時のリサンプリングとビットパーフェクト条件**:
   - 内蔵スピーカー、アナログ変換アダプター、Bluetooth 出力時は Android の AudioFlinger ミキサー（多くは 48 kHz 基準）を経由するためビットパーフェクト再生にはなりません。ビットパーフェクト出力は Android 14 以降かつ接続した USB DAC と端末 HAL の双方が `AudioMixerAttributes.MIXER_BEHAVIOR_BIT_PERFECT` をサポートし、優先モードを ON にした場合にのみ成立します（成立時は端末側の音量ボタンではなく USB DAC 側のハードウェア音量制御となります）。
4. **対応コーデックの範囲**:
   - 再生可能な音声形式は Android 標準 MediaCodec および Media3 Extractor がサポートする形式（FLAC, WAV, MP3, AAC/M4A, ALAC [端末デコーダー対応時], OGG Vorbis, Opus 等）に準拠します。DSD (`.dsf` / `.dff`) や WMA / APE 等の独自形式は標準デコーダー対象外です。
